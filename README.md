# 도깨비의 세계 — 개발 후보

개인용 이미지 인식 자동화 프로그램의 후보 소스와 검사를 관리한다.
이 폴더는 설치본이 아니며, 커밋이나 병합은 배포 또는 실제 게임 검증을 의미하지 않는다.

현재 프로그램·점검기·실전 정상 작동은 전체 검증이 완료되지 않았다.
저장 화면 검사, 가짜 입력 검사, 실제 게임 실행 결과를 구분해서 기록한다.

## 관리 범위

- 검토한 `owner_*.py`, `test_*.py`, `bootstrap.py`
- 협업 규칙과 변경 이력
- 실행 중 설치본, 진단자료, 캐릭터 정보, 설정, 키, 원본 바이너리, 백업은 제외

GitHub 원격 저장소 연결과 최초 업로드는 아직 완료되지 않았다.

## 협업

[COLLABORATION.md](COLLABORATION.md)의 파일 담당과 검증 규칙을 따른다.
서명·빌드·설치·서버 배포는 별도 절차로 수행한다.
